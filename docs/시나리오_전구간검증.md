# 테니스 레슨 SaaS — 전 구간 상세 시나리오 (v6 검증)

> 기획서 v6의 모든 섹션을 **구체적 인물의 행동 → 시스템 반응** 순서로 끝까지 따라간다.
> 걸리는 지점은 ⚠️(빈틈)와 ❓(의문점)로 표시. 마지막 장에 종합.

## S1. 센터 온보딩 — 김대표의 셀프 가입

1. 김대표가 지인 소개로 사이트 접속 → "무료로 시작하기"
2. 휴대폰번호 입력 → OTP 6자리 문자 수신 → 입력 → 인증 완료
3. 약관·개인정보 동의 → 센터명 "그린코트" 입력 → **센터(테넌트) 자동 생성**, 김대표 = 첫 관리자
4. 홈 진입 → **초기 세팅 체크리스트**(0/5)가 상단에 고정
   - ① 영업시간 07:00~22:00, 슬롯 단위 20분
   - ② 상품 등록: "평일 주1회 20분 1인 / 월 4회 / 18만원", "쿠폰 5회 / 4주 / 22만원"
   - ③ 계좌정보 입력
   - ④ 정책: 전부 기본값 유지(취소 24h·유예 7일·외상 허용·홀드 6개월)
   - ⑤ 코치 등록: 본인이 코치 겸직이므로 자기 자신을 코치로 등록
5. **슬롯 열기**: 요일 반복(월~토), 07:00~22:00, 20분 간격 → 빈 슬롯 대량 생성
6. 기존 수기 장부 회원 12명 → **엑셀 일괄 등록**(이름·번호·상품·고정 요일시간) → 12명 생성 + 초대 문자 일괄 발송

**⚠️ 빈틈 S1-a (구조적·중요): 한 전화번호 = 여러 역할/여러 센터.**
김대표가 다른 테니스장 "블루코트"의 **회원**이기도 하다면? 번호가 곧 계정인데,
같은 번호가 그린코트의 관리자이자 블루코트의 회원이다. 현재 문서는 계정과 역할을
구분하지 않음. → **"계정(사람, 번호 1개) ↔ 멤버십(센터별 역할)" 분리**가 필요.
로그인 후 소속이 여럿이면 센터/역할 선택 화면. (회원이 이사 가서 두 센터 다니는 경우도 동일)

**⚠️ 빈틈 S1-b: 셀프 가입 남용 방어.**
누구나 무료로 센터를 만들 수 있으면 장난·스팸 센터가 생긴다.
→ 가입 rate limit + "회원 0명·N개월 미접속 센터 자동 정리" 정책 필요.

## S2. 회원 온보딩 — 박서연 (온라인) & 오할머니 (오프라인)

### 박서연 (앱 사용)
1. 퇴근길 방문 → 상담 → 목 10:00 주1회 결정, 현장에서 계좌이체
2. 김대표(관리자)가 회원 생성: 이름·번호 + 코치(본인)·목 10:00 배정 + 상품 선택
3. 이체 확인 → **결제 승인 + 금액 180,000원 기록** → 지갑 4회 충전
4. 데스크 모니터의 **초대 QR**을 박서연이 그 자리에서 스캔 → 번호 입력 → OTP → 약관 동의 → **활성화 완료**
5. 로그인하면 이미 보임: 지갑 4/4회, 다음 레슨 "목 10:00 · 김대표 코치"
6. PWA 설치·알림 허용 안내 배너 → 설치

- 슬롯 배정 시 목 10:00이 이미 차 있으면 배정 불가(빈 슬롯 계산 공용) ✅
- 결제 확인과 활성화는 독립 — 순서 무관 ✅

### 오할머니 (앱 미사용)
1. 김대표가 회원 생성(이름·번호), 수 09:00 배정, 현금 수령 → 승인+금액 기록
2. 초대 문자는 가지만 오할머니는 열지 않음 → **미활성화(오프라인 회원)** 상태로 정상 운영
3. 출석은 매주 김대표가 수동 처리, 갱신 안내는 문자로만
4. 6개월 뒤 손주가 대신 활성화해줌 → 기록 전부 그대로 이어짐 ✅

**⚠️ 빈틈 S2-a: 타 센터 기존 회원의 번호 등록.**
박서연이 이미 "블루코트" 회원이라면, 그린코트에서 같은 번호로 생성 시 어떻게 되나?
S1-a와 동일 뿌리 — 계정은 하나, **그린코트 멤버십이 추가**되는 것으로 정의해야 함.
회원 앱에는 센터 전환 UI 필요(소속이 2개 이상일 때만 노출).

## S3. 매주 유지 사이클 — 이수민의 화요일

1. 월요일 저녁: "내일 20:00 레슨" 리마인더 웹푸시
2. 화 19:55 도착 → **출석 QR 체크** → 지갑 −1 (잔여 3), 화면에 "오늘 2/4회차"
3. 수업 20분 진행 → 끝

**⚠️ 빈틈 S3-a (중요): QR의 방향과 유효 범위가 미정의.**
"출석 QR"이 정확히 뭔지 문서에 없다. 두 방식이 가능:
- (a) **센터 게시형**: 데스크/코트에 붙은 센터 QR을 회원 앱으로 스캔 → 내 오늘 레슨 출석
- (b) **회원 제시형**: 회원 앱이 QR을 띄우고 코치가 스캔
→ (a)가 코치 손이 안 가서 간편. 추천 (a) + **유효 시간 창**(레슨 시작 전후 N분, 예: −15분~+20분)
필요 — 아무 때나 찍는 부정 출석 방지. 시간 창 밖이면 "코치에게 문의" 안내.

**⚠️ 빈틈 S3-b: 아무도 안 찍은 레슨(미처리).**
회원은 QR 깜박, 코치도 수동 처리 깜박 → 레슨이 출석도 취소도 아닌 채 지나감.
차감이 안 돼 지갑이 안 맞기 시작. → **"미처리 레슨" 목록**을 관리자 처리 큐에 노출,
관리자/코치가 사후에 출석·노쇼·취소 중 지정. (자동 노쇼 처리는 하지 않음 — "판단은 사람" 원칙)

## S4. 결번 — 사유·규모별 전 케이스

### 4-1. 사전취소 (이수민, 회사 야근)
1. 월요일(24h 전) 앱에서 "이번 회차 취소" → 즉시 처리, 차감 없음(잔여 유지)
2. 화 20:00 슬롯은 **그 주에 한해 빈칸으로 풀림** → 다른 회원(최유나 등)이 셀프 예약 가능
3. 이수민의 남은 회차는 다음 주 화요일이 자동 소비하거나, 본인이 아무 빈 슬롯에 셀프 예약

**⚠️ 빈틈 S4-a: "취소된 정기 슬롯은 그 주 빈칸이 된다"가 문서에 명시 안 됨.**
지갑 모델의 자연 귀결이지만 3.4 빈 시간 계산 정의에 한 줄 필요.

### 4-2. 늦은 취소 (당일 오후)
1. 화 14:00에 취소 시도 → UI 경고 "규정 시간(24h)이 지나 지금 취소하면 1회 차감됩니다"
2. 진행 시 노쇼(사유: 늦은 취소)로 기록, 차감 → 관리자가 사정 들으면 **회차 복구** 가능 ✅

### 4-3. 노쇼 (연락 없이 안 옴)
1. 코치가 "노쇼" 처리 → 차감(기본) + 회원에게 알림
2. 노쇼 대시보드에 기록 → 커뮤니케이션 후 복구/유지 판단
3. 반복 시: 1회 알림 → 2회 경고 문자 → 연속·연락두절 → 휴면 전환 제안 ✅

**❓ 의문 S4-b: 유예 중(잔여 0) 노쇼면?** 외상 −1과 결합해 −2까지 갈 수 있음.
→ 허용하되 유예 만료 때 함께 정산(음수는 재충전 시 차감). 큰 문제는 아니나 명시 권장.

### 4-4. 대회 (토요일 일부 결번)
1. 회원 8명이 대회 참가 → 각자 사전취소 or **관리자 일괄 사전취소**(명단 선택 → 한 번에)
2. 각자 차감 없음 + 알림. 안 나가는 토요일 회원은 정상 출석 ✅

### 4-5. 공휴일 (전원 결번)
1. 관리자가 **휴강일 지정**(추석 연휴) → 해당일 레슨 전체 휴강 + 일괄 알림 + 차감 없음 ✅

### 4-6. 코치 개인 사정 휴강
1. 한코치가 금요일 휴강 신청 → **관리자 승인** → 금요일 담당 레슨 전체 휴강 처리 + 회원 알림 ✅

## S5. 예약 변경 — 이원화 검증

### 5-1. 이번 주만 이동 (즉시)
1. 이수민: 화 20:00 → 목 19:00(빈 슬롯)으로 "이번 주만 이동"
2. 확인 모달 → 즉시 확정. 원래 화 슬롯은 그 주 빈칸으로
3. **관리자·코치에게 알림**: "이수민님이 화20:00→목19:00 변경" ✅
4. 센터 설정의 고삐: 당일 변경 불가 / 월 2회 제한 등 (기본값 관대)

### 5-2. 고정 요일·시간 자체 변경 (승인)
1. 이수민: "다음 달부터 계속 목 19:00으로" 요청 → 관리자 처리 큐로
2. 김대표가 요금(평일 동일)·스케줄 확인 → 승인 → 고정 스케줄 규칙 변경, 이후 레슨 재생성

**⚠️ 빈틈 S5-a: 승인 시점 재검증.**
요청과 승인 사이에 목 19:00을 다른 회원이 잡을 수 있다.
→ **승인 시점에 빈 슬롯 재검증**, 이미 찼으면 승인 불가 + 요청자에게 안내. (구현 규칙으로 명시)

## S6. 갱신 · 유예 · 외상 — 박서연의 마지막 회차

1. 잔여 1회 시점 → 갱신 알림(문자+푸시)
2. 목 10:00 마지막 출석 → 잔여 0 → **유예기간 7일 시작.** 슬롯 보장, 알림: 즉시 → 3일 후 → 만료 전날
3. 관리자 처리 큐에 "충전 대기: 박서연" 표시 → 김대표가 전화 한 통
4. **케이스 A**: 5일째 입금 → 승인 → 재충전 → 아무 일 없던 듯 계속 ✅
5. **케이스 B**: 유예 중 목요일이 먼저 옴 → 외상 허용(기본) → 수업 진행, 잔여 −1 → 이후 충전 시 4−1=3부터 ✅
6. **케이스 C**: 무응답 → 만료 전날 최종 경고 → 해제, 목 10:00 빈칸. 2주 뒤 재등록 시 그 슬롯이 아직 비어있으면 복귀 ✅
7. **케이스 D**: "그만둘게요" 명시 → 즉시 해제 ✅

**❓ 의문 S6-a: 유예 중 잔여 회차가 남아있는 유효기간 만료와의 관계.**
유예는 "잔여 0"에서 시작. 반대로 "잔여 있는데 유효기간 만료"는 3.1대로 소멸(관리자 연장 가능).
두 트랙이 다른 규칙임을 문서에 대비시켜두면 혼동 방지.

## S7. 홀드 — 이수민의 해외 출장 6주

1. 이수민이 인포에 요청(전화/방문) → 관리자가 홀드 등록: 3/1~4/12
2. 홀드 중: 레슨 미생성 · 차감 없음 · **유효기간 정지** · 화 20:00 슬롯은 유지
3. 4/13 자동 해제 → 화 20:00부터 정상 재개, 리마인더 재개 ✅

**❓ 의문 S7-a: 홀드 중 빈 코트 활용.**
6주간 화 20:00이 비어 돈다. 이 슬롯을 "홀드 기간 한정 임시 개방"해 다른 회원의
일회 예약을 받을지? (수익 보전 vs 복잡도 증가) → 센터 설정 후보. 결정 필요.

## S8. 회차제 — 최유나의 쿠폰 5회

1. 등록: 쿠폰 5회/4주, 고정 스케줄 없음(지갑만)
2. 앱에서 코치별 빈 슬롯 보기 → 목 15:00 예약 → "수업권 1회가 차감됩니다" 확인 → 즉시 확정
   (지갑이 2개면 여기서 어느 지갑인지 선택)
3. 출석 → −1. 취소 규정은 정기와 동일(24h) ✅
4. 잔여 1회 → 알림 / 만료 3일 전 & 잔여 있음 → 알림 (둘 다)
5. 만료 시 잔여 소멸(기본), 부상 등 사정은 관리자가 유효기간 연장 ✅

**⚠️ 빈틈 S8-a: 회차제 회원에겐 "유예"가 없다 — 의도 확인.**
유예는 고정 슬롯 보호 장치라 슬롯 없는 회차제엔 해당 없음(재구매하면 그만).
맞는 설계지만 "유예 = 정기(고정 스케줄) 전용"임을 명시해야 혼동이 없다.

## S9. 2인 레슨 — 정민호·정하늘 부자

1. 등록: 2인 상품(토 11:00), **각자 회원 생성 + 각자 지갑(2인가) + 같은 슬롯 공유**
2. 매주: 둘 다 각자 QR → 각자 −1
3. 하늘이만 시험공부로 사전취소 → 하늘이 잔여 유지, 민호는 정상 출석·차감. 레슨은 1명으로 진행
4. 하늘이의 남은 회차 → 빈 슬롯에 일회 보강 예약 ✅
5. 하늘이가 아예 중단 → 하늘이 스케줄만 해제. 민호는 유지하되 **상품을 1인가로 변경**(관리자 재량, 요금 차이 정산은 인포 처리) ✅

**❓ 의문 S9-a: 슬롯 해제 조건.** 2인이 공유한 슬롯은 **둘 다** 해제(중단·유예만료)되어야 빈칸.
한 명 남으면 슬롯 유지. — 자연스러운 규칙이지만 명시 권장.

---

## S10. 코치 — 합류·권한·퇴사

1. 센터 성장 → 김대표가 한코치 생성(이름·번호) → 초대 → OTP 활성화 (회원과 동일 패턴)
2. 기본 권한: 자기 스케줄·출석 처리·레슨 노트. 김대표가 **"결제 승인" 권한 추가 부여**
3. 한코치가 권한으로 결제 승인 시 → **처리 주체 기록** + 알림에 표시 ✅
4. 1년 뒤 퇴사 → 관리자가 **비활성 처리** → 부여 권한 자동 소멸 → 담당 회원 12명을 김대표에게 **일괄 이관**(각 회원에게 "담당 코치 변경" 알림) ✅

**❓ 의문 S10-a: 이관 시 고정 슬롯 충돌.** 한코치의 화 20:00 회원을 김대표에게 이관하는데
김대표의 화 20:00이 이미 차 있으면? → 충돌 목록을 보여주고 관리자가 개별 조정(시간 변경 협의).
자동 해결 불가 — 화면 요구사항으로 명시 필요.

---

## S11. 관리자의 하루 — 김대표의 화요일

1. **아침, 통합 처리 큐**: 결제 승인 2 · 고정 변경 요청 1 · 취소 신청 1 · 충전 대기 1 · 미처리 레슨 2 · 휴강 신청 1
2. 이체 확인 → 승인 2건(+금액 기록) / 고정 변경은 슬롯 재검증 후 승인 / 미처리 레슨은 코치 확인 후 출석 지정
3. 낮: 본인 레슨 진행, QR 안 찍은 오할머니 수동 출석
4. 저녁: 노쇼 1건 발생 → 노쇼 처리, 대시보드에서 이전 이력 확인(첫 노쇼 → 알림만)
5. 밤: 다음 주 대회 명단 8명 일괄 사전취소, 공지 작성(대회 안내, 이미지 첨부)
6. 월말: 매출 통계(이번 달 승인 금액 합계), 반기 합계로 세금 신고 참고 ✅

---

## S12. 종료 계열 — 휴면·탈퇴·센터 해지

1. **휴면**: 노쇼 연속+연락두절 회원 → 휴면 전환 → 슬롯 해제. 복귀 시 관리자가 재활성 ✅
2. **탈퇴**: 회원이 앱에서 탈퇴 → 개인정보 파기(결제 기록은 법정 기간 보관)
   ⚠️ **빈틈 S12-a: 잔여 회차가 있는 탈퇴** — "잔여 3회가 소멸됩니다" 경고 + 환불은 인포 재량 안내. UI 요구사항으로 명시 필요.
3. **센터 해지**: 김대표가 폐업 → 해지 신청 → 센터 비활성 → 소속 회원 전원에게 문자 안내 → 데이터 보관 기간 후 파기
   ❓ **의문 S12-b: 해지 시 회원 안내 문자** — 필요해 보이나 문서에 없음.
