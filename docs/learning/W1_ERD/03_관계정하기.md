# [과제 3] 관계 정하기

> 예상 25분. 기계적인 작업입니다 — 아래 순서를 그대로 따라가세요.
> 막히면 "힌트 줘"라고 하시면 됩니다.

## 방법

각 쌍마다 **"몇 개?"를 두 번** 묻습니다.

```
① 왼쪽 1개는 오른쪽을 몇 개 갖나?
② 오른쪽 1개는 왼쪽을 몇 개 갖나?

  한쪽만 "여러 개"      → 1:N,  FK는 "여러 개"라고 답한 쪽의 반대편 테이블에
  양쪽 다 "여러 개"     → N:M,  중간 테이블을 새로 만든다
```

## 시범 (2교시에서 함께 푼 것)

| 쌍 | ① | ② | 관계 | FK 위치 |
|---|---|---|---|---|
| membership ↔ lesson_pass | 여러 장 | 1명 | 1:N | `lesson_pass.membership_id` |
| standing_schedule ↔ lesson | 여러 개 | 1개 | 1:N | `lesson.standing_schedule_id` |
| account ↔ center | 여러 개 | 여러 개 | **N:M** | 중간 테이블 `membership` 생성 |
