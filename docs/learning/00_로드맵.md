# FORTYALL:DESK 학습 로드맵 (6주 스프린트)

> 기간: 2026-08-08(금) ~ 09-16(화) · 주당 35시간+ · 목표 = **실제 AWS URL에서 돌아가는 MVP + 부하테스트 수치**
> 최종 목표는 결과물이 아니라 **백엔드 개발자로 취업할 실력**. 그래서 속도보다 "왜"를 먼저 이해하고 넘어간다.

## 원칙

1. **Walking Skeleton 먼저.** 기능을 다 만들고 마지막에 배포하지 않는다. 2주차에 "로그인만 되는 빈 껍데기"를 AWS에 올려 실제 URL을 먼저 확보한다. 배포는 미룰수록 지옥이 된다.
2. **수직 슬라이스.** 엔티티만 10개 만들고 서비스로 넘어가지 않는다. 기능 하나를 DB→API까지 관통시키고 다음으로.
3. **막히면 3회 룰.** 같은 문제로 3번 시도해서 안 되면 멈추고 접근을 바꾼다.
4. **면접 대비 동시 진행.** 각 주차마다 "이 주제로 면접에서 나오는 질문"을 정리한다.
