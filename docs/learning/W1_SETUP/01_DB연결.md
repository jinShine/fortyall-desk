## Step 1. 왜 이런 일이 생기나 (읽기만, 3분)

`build.gradle`에 이 줄이 있습니다.

```gradle
implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
```

Spring Boot는 **클래스패스에 뭐가 있는지 보고 알아서 설정을 만듭니다.** 이걸 자동 구성(Auto Configuration)이라 합니다.
JPA 스타터가 있으니 "아 이 앱은 DB를 쓰는구나" 하고 DataSource를 만들려 하는데,
접속 주소를 못 찾아서 포기한 겁니다.

> **선택지는 두 가지입니다.**
> ① DB를 붙인다 ② JPA 스타터를 뺀다
>
> 우리는 ①로 갑니다. 실제 MySQL을 쓸 거니까요.

## Step 2. Docker로 MySQL 띄우기

### 왜 Docker인가

MySQL을 맥에 직접 설치하면 이런 게 따라옵니다.
- 버전이 맥 전체에 하나뿐이라 다른 프로젝트와 충돌
- 지우고 다시 깔기가 번거로움
- 팀원·서버와 버전이 미묘하게 다름

Docker는 프로젝트마다 격리된 MySQL을 두고, 통째로 지웠다 다시 만들 수 있습니다.

### I do — 제가 먼저 예시를 하나 보여드립니다

우리 프로젝트가 아니라 **가상의 블로그 서비스**용 PostgreSQL이라고 칩시다.
각 줄이 무슨 뜻인지 주석으로 달아뒀습니다.

```yaml
services:                              # 띄울 컨테이너 목록
  db:                                  # 서비스 이름 (내 맘대로)
    image: postgres:16                 # 어떤 이미지를 쓸지 (이미지:태그)
    container_name: blog-postgres      # 컨테이너 이름 (docker ps 에 보임)
    ports:
      - "5432:5432"                    # "내 맥의 포트 : 컨테이너 안의 포트"
    environment:                       # 이미지가 읽는 환경변수 (이미지마다 다름)
      POSTGRES_PASSWORD: blog
      POSTGRES_DB: blog_db
    volumes:
      - blog-data:/var/lib/postgresql/data   # 데이터를 컨테이너 밖에 저장

volumes:
  blog-data:                           # 위에서 쓴 이름의 볼륨을 선언
```

**여기서 꼭 이해하고 넘어갈 두 가지**

**① `ports: "5432:5432"` 의 왼쪽과 오른쪽**
왼쪽은 내 맥에서 접속할 포트, 오른쪽은 컨테이너 안에서 DB가 듣고 있는 포트입니다.
왼쪽만 바꾸면 됩니다. 예를 들어 `"5433:5432"` 로 두면 내 맥에서는 5433으로 붙습니다.

**② `volumes` 가 없으면 데이터가 사라집니다**
컨테이너를 지우면 그 안의 파일도 같이 사라집니다. 볼륨은 컨테이너 **밖**에 있는 저장 공간이라,
컨테이너를 지웠다 다시 만들어도 데이터가 남습니다.

### You do — 이제 우리 것을 직접 작성하세요

프로젝트 루트에 `docker-compose.yml` 을 만들고 채워보세요.

```yaml
services:
  mysql:
    image: mysql:8.4
    container_name: fortyall-mysql
    ports:
      - "____:____"          # ← 3306 을 쓰세요
    environment:
      MYSQL_ROOT_PASSWORD: ____
      MYSQL_DATABASE: ____         # ← DB 이름. fortyall_desk 로 하죠
      MYSQL_USER: ____
      MYSQL_PASSWORD: ____
      TZ: Asia/Seoul
    volumes:
      - ____:/var/lib/mysql        # ← 볼륨 이름은 자유. mysql-data 정도

volumes:
  ____:                            # ← 위에서 쓴 이름과 똑같이
```

작성했으면 띄웁니다.

```bash
docker compose up -d      # -d = detached, 백그라운드로
docker compose ps         # 떠 있는지 확인
```

**질문 2.** `docker compose ps` 결과에 `PORTS` 열이 보일 겁니다. 거기 뭐라고 쓰여 있나요?
그 표기가 위에서 배운 "왼쪽:오른쪽"과 어떻게 대응되나요?

## Step 3. application.yaml 작성

이제 앱에게 "DB 여기 있다"고 알려줄 차례입니다.

`src/main/resources/application.yaml` 은 지금 이렇게 3줄뿐입니다.

```yaml
spring:
  application:
    name: fortyall-desk
```

### 채워야 할 것

```yaml
spring:
  application:
    name: fortyall-desk

  datasource:
    url: jdbc:mysql://localhost:____/____?serverTimezone=Asia/Seoul&characterEncoding=UTF-8
    username: ____
    password: ____

  jpa:
    hibernate:
      ddl-auto: ____
```

**`ddl-auto` 는 네 가지 중에 고릅니다.** 지금 우리 상황에 뭐가 맞을까요?

| 값 | 하는 일 |
|---|---|
| `none` | 아무것도 안 함. 테이블은 내가 SQL로 직접 만든다 |
| `validate` | 엔티티와 테이블이 맞는지 검사만. 다르면 앱이 안 뜸 |
| `update` | 엔티티를 보고 테이블을 만들거나 컬럼을 추가 (삭제는 안 함) |
| `create-drop` | 뜰 때 만들고 내려갈 때 지움 |

**질문 3.** 지금은 엔티티가 하나도 없고 앞으로 계속 늘어날 겁니다. 어떤 걸 고르시겠어요? 왜죠?

→ 여기에 답:

> 참고: `url` 의 `characterEncoding=UTF-8` 이 없으면 한글이 `???` 로 들어갑니다.
> 실제로 겪으면 원인 찾느라 한참 걸리는 종류라 처음부터 넣습니다.
